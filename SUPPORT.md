# Support

## Getting help

- Read the [README](README.md), [verification guide](docs/verification.md) and [installation guide](docs/installation.md) first.
- Search existing issues before opening a new one.
- For a broken or outdated entry, open an issue with the resource ID and the evidence.
- For a security concern, follow [SECURITY.md](SECURITY.md) instead of opening a public issue.

## What maintainers can help with

- catalog structure, schema and validation questions
- adding or correcting an entry
- verification and license questions about a listed resource
- documentation and contribution process
- CI and tooling issues in this repository

## What maintainers cannot help with

- debugging or installing an upstream third-party resource
- bypassing an upstream license or paywall
- unauthorized security testing
- support for abandoned or unmaintained upstream projects
- guaranteeing that a resource is safe or compatible with your setup

## Before asking for help

Include:

1. The resource ID or file path.
2. What you expected to happen.
3. What actually happened.
4. The verification command output, if relevant.
5. Your OS and Python version for tooling issues.

Do not paste secrets, tokens or private data.

## Response expectations

This is a volunteer project. Response times vary. A clear, reproducible report with evidence is the fastest route to a fix.
