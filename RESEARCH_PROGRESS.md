# Research Progress

Last updated: 2026-11-05

## Sources used

- GitHub REST API (`gh api repos/<owner>/<repo>`) for repository existence, stars, license, last push and archived status
- npm registry metadata (`npm view`) for package existence, version and license
- PyPI JSON API for package existence, version, license and summary
- The original project brief and follow-up discovery notes

## Domains covered

Software development, mobile, Android/custom ROM, Linux/kernel, databases, DevOps, cybersecurity, AI/ML, data science, game development, design, image, video, audio, content/marketing, documents/productivity, education/research and business/finance.

## Domains with thin standalone coverage

DevOps, AI/ML, data science, game development, audio and business currently rely mostly on skill packs rather than standalone verified entries. This is recorded as a gap, not hidden.

## Not done

- Individual skill counts inside large packs were not independently verified.
- Upstream READMEs were not treated as proof of functionality.
- No market or star-based ranking was produced.
- No web search was used as sole evidence for a catalog entry.
