# Changelog

All notable changes to this project are documented here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and the project uses semantic versioning for its own data and tooling.

## [Unreleased]

### Added

- 91 verified ecosystem resources: 50 plugins, 24 skills, 8 MCP servers, 8 themes and 1 agent.
- New `theme` resource type, `catalog/themes.json`, schema support and nine-type documentation.
- Theme-aware catalog expansion from GitHub API discovery: 757 unique repositories reviewed.
- Expansion reports: discovery, additions, duplicates, verification, licenses, security, coverage, tests and quality scorecard.
- Isolated Docker installation harness (`scripts/run_installation_tests.py`) with pinned cases and evidence.
- Four installation smoke tests; three resources promoted to `INSTALLATION_TESTED`.
- Manual GitHub Actions workflow for installation tests.
- Tests for installation-case safety and pinning.
- Website readiness audit and MVP implementation plan.
- Category-first README with all 18 categories near the top, sorted by coverage.
- Query tool for filtering and sorting the catalog: `scripts/query_catalog.py`.
- Contributor resources: `docs/faq.md`, `docs/resource-template.md`.
- `Makefile`, `.editorconfig`, `.gitattributes` and `.gitignore`.
- Breadcrumbs and quick-facts blocks on generated category and collection pages.
- Unit tests for filtering, sorting and JSON/ID output.
- Theme-aware SVG banner and category coverage chart, generated by `scripts/generate_assets.py`.
- CI drift check for generated assets.
- README hero with theme-aware artwork, live workflow badges and keyboard-style quick navigation.

### Changed

- README rewritten for faster discovery, clearer trust signals and safer install guidance.
- `categories/README.md` now sorts categories by resource coverage, then alphabetically.

### Fixed

- Removed previously committed Python bytecode and ignored future artifacts.

### Planned

- Expand verified standalone coverage in audio, content, business and game development categories.
- Add functional tests and source-code security audits for high-trust resources.
- Add a schema-driven static website with search and filters.
- Add scheduled source re-verification and license drift detection.

## [0.1.0] - 2026-11-05

### Added

- Initial repository structure, MIT license, governance and security documentation.
- JSON schemas for resources, catalog files and collections.
- Structured catalog split by resource type: skills, agents, plugins, MCP servers, commands, rules, hooks and providers.
- Role collections and upstream skill-pack/toolkit collections.
- Raw discovery inventory preserving every entry from the initial brief, including unresolved and restricted items.
- Validation script for schemas, IDs, categories, duplicates and references.
- Link checker for local Markdown links and optional external URL probing.
- Deterministic index and report generators.
- Eighteen category pages generated from catalog data.
- Evidence reports for statistics, missing sources, licenses, compatibility and security.
- Unit tests for validation, generation and link checking.
- GitHub Actions workflows for validation, generation drift, tests, Markdown linting and link checks.
- Restricted archive policy for permission-bypass and guardrail-removal tooling.

### Notes

- No third-party resource was installed on the host during cataloging. Installation tests are reported as `NOT_TESTED`.
- Source and license verification was performed against GitHub, npm and PyPI metadata on 2026-11-05.
- Upstream claims are kept separate from independently observed facts.
